# 📺 IPTV — Halaman Pemutar Siaran

Antarmuka yang lebih ramah untuk koleksi saluran iptv-org.

## Cara Menggunakan
1. Buka halaman utama
2. Cari atau saring saluran yang diinginkan
3. Klik untuk menonton langsung di halaman
4. Bagikan ke teman atau salin kode sematkan untuk ditampilkan di situs Anda

## Fitur
- ✅ Pemutar terintegrasi (tidak butuh aplikasi eksternal)
- ✅ Cari & saring berdasarkan negara/kategori
- ✅ Mode gelap/terang
- ✅ Kode sematkan siap pakai
- ✅ Bagikan ke WhatsApp, Telegram, dll
- ✅ Tautan M3U untuk pemutar lain
